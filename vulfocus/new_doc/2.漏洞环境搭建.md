# 漏洞环境搭建

## 1. 安装docker-ce

### 首先解决网络问题

接下来会用到“curl”，“apt”，它们会使用http请求访问国外docker网站服务器下载资源，这需要配置代理。

**给当前用户的系统环境变量添加临时代理：**
（apt默认在 **root** 下运行，需要给 **root 用户**添加临时环境变量，所以以下命令需登录root执行 ）**

```bash
# export：将变量声明为环境变量，使其在当前 shell 会话及子进程中生效。
export HTTPS_PROXY="http://192.168.10.8:7890"
export https_proxy="http://192.168.10.8:7890"
```

### 进行安装操作

通过下面的命令实现给 apt 添加 docker 的官方软件源，并对该源进行配置（gbg 路径与软件包 amd64 架构）:

```bash
# deb [选项] <仓库URL> <发行版代号> <组件>
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian bookworm stable" | \
sudo tee /etc/apt/sources.list.d/docker.list
```

从官网下载验证密钥并导入：

```bash
curl -fsSL https://download.docker.com/linux/debian/gpg | \
sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
# --dearmor, 将ascll格式的密钥转化为二进制
```

更新软件源，进行安装最新版的docker-ce：

```bash
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io
```

## 2. 为docker hub配置镜像

在 docker 官网上下载资源比较慢，甚至不可达，需要在国内 docker 镜像站上面下载。

```bash
sudo mkdir -p /etc/docker
# 修改docker配置文件daemon.json
sudo tee /etc/docker/daemon.json <<EOF
{
    "registry-mirrors": [
        "https://docker.1ms.run",
        "https://docker.xuanyuan.me"
    ]
}
EOF
sudo systemctl daemon-reload   #  systemd重新加载配置文件
sudo systemctl restart docker  # 重新启动docker服务
```

## 3. 拉取并配置vulfocus

使用 docker 拉取 vulfocus 镜像

```bash
docker pull vulfocus/vulfocus:latest
```

<img src="images\vulfocus-install.png" alt="windows" style="zoom:63%;" />

初始化并运行该镜像

```bash
docker run \         # 创建并运行
-p 80:80 \           # 端口映射，虚拟机ip+80端口就可以访问该容器80端口
-v /var/run/docker.sock:/var/run/docker.sock \
-e VUL_IP=0.0.0.0 \  # 监听外部所有的ip的请求
vulfocus/vulfocus:latest
```
