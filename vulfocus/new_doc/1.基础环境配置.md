# 虚拟机基础环境配置

## 1. 虚拟机环境

**虚拟化平台：** virtualBox 7.1.8

**kali安装版本：** kali-linux-2025.1c-installer-amd64.iso

**虚拟机配置硬件信息：**

网络， net网卡+host-only网卡

内存， 4g

磁盘， 50g

## 2. root用户设置密码

```bash
sudo su
sudo password root
```

## 3. 网络文件配置

```bash
sudo vim /etc/network/interfaces
```

**添加：**

>allow-hotplug eth0
>
>iface eth0 inet dhcp 
>
>allow-hotplug eth1
>
>iface eth1 inet dhcp

配置好如下图所示：

<img src="images\network.png" alt="windows" style="zoom:63%;" />

**拔插网卡,重新启动网络服务：**

```bash
sudo ifdown eth0 && sudo ifup eth0
sudo ifdown eth1 && sudo ifup eth1
```

## 4. SSH配置

**打开ssh配置文件：**

```bash
sudo vim /etc/ssh/sshd_config
```

**设置开启root用户使用ssh登录，开启公钥验证登录：**

>PermitRootLogin yes
>
>PubkeyAuthentication yes

**配置图片：**

<img src="images\SSH_config.png" alt="windows" style="zoom:63%;" />

**添加开机启动,并重启服务**

>systemctl enable ssh
>
>service ssh restart
